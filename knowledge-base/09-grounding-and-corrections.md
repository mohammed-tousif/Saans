# Grounding contract and correction register

Updated 18 November 2026 by Codex. Read before resuming with any model.

## Evidence rules

- Official rules need current organizer evidence. A previous model statement is not a source.
- Distinguish implemented, unit-tested, browser-tested, live-service-verified and deployed.
- Every advice sentence needs claim-level support, applicability and limitations. A real URL alone does not prove support.
- New catalogue entries default to disabled. Enable only after review and regression tests.
- Never promise a ranking, elimination of all hallucinations, or measured health benefits.
- Unknowns remain unknown. Keep handoff records current after each work chunk, not only at quota exhaustion.

## Corrected inherited defects

- CAMS Global atmospheric composition is approximately 45 km, not the European 11 km product. Explicit global domain is now requested. Source: https://open-meteo.com/en/docs/air-quality-api
- Local timestamps need their returned UTC offset. Unknown and implausible future times cannot count as fresh.
- Replanning must update the actual profile before rule filtering. Free-text instructions alone do not enforce constraints.
- Compare against the original server snapshot, not a regenerated baseline.
- Damp-cloth mask advice and unqualified cleaner-morning advice were removed. Eight unreviewed action records are disabled.
- Elderly household members do not automatically imply mobility limitations.
- Rate-limit configuration alone is not enforcement. Process-local limits now exist; distributed deployment requires stronger controls.
- A model-selected citation does not prove support. The model now only ranks eligible IDs; rendered advice and citations come from the reviewed catalogue.
